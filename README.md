# EDZ Films — LP de orçamento

Landing page de captação de leads (anúncios Facebook/Instagram).
Publicada em https://elieldnz.github.io/edz-orcamento/ · site principal: https://elieldnz.github.io/edz-films-site/

Configuração no topo do `<script>` de `index.html`: WhatsApp, planilha (SHEETS_URL), custos de deslocamento, nota fiscal (NOTA) e pacotes.
Para anúncios, use `?servico=fotos|reels|cortes|captacao|evento` e parâmetros UTM; a coluna "Origem" da planilha guarda tudo isso.
